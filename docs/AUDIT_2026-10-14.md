## New: native backend (`src/native/`, `ember native file.em`)

- Lowers the validated, optimized typed IR to LLVM IR, runs LLVM's O2
  pipeline, and JIT-compiles with ORC LLJIT (LLVM 18).
- Covers every IR operation: checked integer arithmetic with the VM's
  traps, floats, strings, arrays, structs, enums, closures with Lua-style
  capture semantics (captured locals live in heap cells; `CloseUpvalues`
  gives the frame a fresh cell, so earlier closures keep the old one).
- Runtime errors match the VM byte for byte, including the stack trace:
  generated code keeps a small frame table (function id + current source
  location) and the call-depth limit.
- Limits (honest): no garbage collector (arena freed at exit, 2 GiB cap,
  exit 6 when reached); `--max-steps`, `--max-heap`, `--gc-stress` and
  `--profile` are VM-only and make `ember native` exit 6; no AOT output;
  not tested under ASan; single-threaded, one run per process at a time.
